Pensada para o uso diário

Menos promessa. Mais controle.

Aurem prioriza uma experiência simples: instalar, abrir e conversar. O que é técnico fica nos bastidores até você precisar.

01

Local por padrão

Conversas e memória podem permanecer no seu computador. O funcionamento principal não depende de enviar cada pergunta para um serviço externo.

02

Feita para computadores reais

Aurem avalia CPU, memória e GPU para escolher um modelo compatível. Em máquinas mais simples, usa uma configuração mais conservadora.

03

Você continua no comando

Downloads maiores e participação na Aurem Mesh exigem uma escolha explícita. Nada disso é ativado escondido durante a instalação.

Como funciona

Privacidade e segurança

Você deve entender o que o software está fazendo.

Por isso, a Aurem separa claramente processamento local, participação em rede e diagnósticos. Recursos que usam outros computadores não são tratados como se fossem a mesma coisa que uma conversa local.

Aurem Mesh

Potência compartilhada, somente quando fizer sentido.

A Mesh é uma camada opcional para tarefas compatíveis. Seu computador pode continuar sendo o cérebro principal enquanto outros nós ajudam em trabalhos específicos. A contribuição fica desligada até o usuário escolher participar.
