# AGENTS.md — Aurem Public Releases

This repository is the **public distribution/release surface for Aurem**. It is not the private Aurem core source repository.

Before editing:
- Confirm the task is about public release assets, downloads, Pages, or release-facing documentation.
- For Aurem core logic, route to `williamoleo-creator/aurem-remote`.
- Never publish private source, tokens, service credentials, signing secrets, device secrets, or internal infrastructure secrets here.
- Prefer versioned release artifacts and reviewed commits.
- Check the latest GitHub Pages deployment after public-site changes.

If the task concerns iMontador, stop and use the iMontador repository instead.
