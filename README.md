# Aurem Remote Commander

**Secure remote computer access for AI assistants and MCP-compatible clients.**

Aurem Remote Commander is being built to let authorized AI clients work with a user's computer remotely while keeping device identity, ownership, command authorization, auditability, and critical-action protection at the center of the design.

## Public distribution

This repository is the official public distribution channel for Aurem releases and the public release site.

- **Official app:** https://aurem-remote-free-prod.web.app
- **Release repository:** https://github.com/williamoleo-creator/aurem-releases
- **Build / deployment status:** https://github.com/williamoleo-creator/aurem-releases/actions

## What Aurem is designed to support

- Remote file access and search
- Terminal and development workflows
- Process execution and monitoring
- Windows agent pairing and device identity
- ChatGPT and MCP-compatible clients
- Remote use from mobile devices
- Secure, auditable command execution

## Source and security

The public repository contains release-facing assets and distribution files. The core Aurem source code remains private while the product is under active development.

Security-sensitive material such as private keys, service credentials, signing secrets, access tokens, and production secrets must never be committed to this repository.

## Projects

Aurem is part of a broader set of products under active development, including **iMontador**, a marketplace focused on furniture-assembly services. Product source repositories can remain private while public release surfaces stay clean and professional.

## Status

Aurem is under active development. Public releases should be treated as versioned software and validated through the project's CI/CD and release process before production use.
